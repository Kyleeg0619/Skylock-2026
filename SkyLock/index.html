Stay focused, Stay productive!

The extension monitors all open browser tabs and detects when the user opens a social media site during an active excursion. When it finds a distracting tab, it sends a message into the SkyLock game so the ExcursionScene can apply penalties in real time. In short, it acts as a bridge between the browser and the game, signaling distraction only while the excursion timer is running.
